# Pi 0.80.6 Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Pi development dependencies to 0.80.6 and clear Superpowers compaction state after the agent fully settles.

**Architecture:** Keep existing compaction reinjection logic unchanged. Upgrade the four coordinated Pi packages, then subscribe the existing cleanup closure to Pi's `agent_settled` event instead of its per-run `agent_end` event.

**Tech Stack:** TypeScript, pnpm, Node test runner, Biome, Pi extension API 0.80.6.

## Global Constraints

- Pin all `@earendil-works/pi-*` development dependency ranges and the Pi coding-agent peer dependency to `^0.80.6`.
- Do not add provider-header hooks or custom entry rendering; this extension does not use them.
- Preserve `superpowersActive` across retries, compaction retries, and queued follow-ups; only clear it at `agent_settled`.
- Keep the user-owned `config.example.json` modification untouched.
