# Pi 0.80.6 Lifecycle Upgrade Design

## Goal

Update development-time Pi packages to `^0.80.6` and clear the Superpowers compaction-durability state only after Pi has fully settled.

## Scope

- Update the four `@earendil-works/pi-*` development dependencies, the Pi coding-agent peer dependency, and the pnpm lockfile.
- Replace the compaction cleanup hook from `agent_end` to `agent_settled`.
- Update lifecycle tests and the unreleased changelog.

## Design

The extension sets `superpowersActive` before sending an opted-in Superpowers prompt. It must remain true through Pi's automatic retry, compaction-retry, and queued follow-up processing so the existing `session_compact` and `context` handlers can re-inject the root contract.

Pi 0.80.6 provides `agent_settled`, emitted only after those automatic continuations finish. The cleanup handler in `registerCompactionDurabilityHandlers` will subscribe to `agent_settled` instead of `agent_end`, then set `superpowersActive` to false. The package will require Pi `^0.80.6` so older hosts cannot load a lifecycle subscription they do not emit. No other lifecycle behavior changes.

## Testing

Update unit and integration mocks/assertions to register and invoke `agent_settled`. The tests must show that cleanup occurs at settlement and that compaction reinjection remains armed before settlement.

## Documentation

Add an Unreleased CHANGELOG entry naming the Pi 0.80.6 dependency update and the corrected settled-lifecycle cleanup.
