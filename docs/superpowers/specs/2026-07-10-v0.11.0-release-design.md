# v0.11.0 Release Design

## Goal

Publish `@teelicht/pi-superagents` version `0.11.0` through the existing GitHub Release and npm Trusted Publishing workflow.

## Scope

- Keep the completed Pi `^0.80.6` upgrade unchanged.
- Upgrade every remaining direct npm development dependency to its current latest release.
- Upgrade the open GitHub Actions dependency targets directly instead of merging stale Dependabot pull requests.
- Regenerate `pnpm-lock.yaml`, update package-manifest coverage, and document the release in `CHANGELOG.md`.
- Set `package.json` to `0.11.0`, verify release gates, commit, push `main`, create tag `v0.11.0`, and publish the GitHub Release.

## Dependency Strategy

Direct upgrades are preferred over the 13 open Dependabot pull requests because their target versions are stale and five fail validation. The release includes the current latest non-Pi direct packages, including TypeScript 7 and Fallow 3, and Actions `actions/checkout@v7` and `pnpm/action-setup@v6`.

## Validation and Release

Run Biome, TypeScript, all tests, `pnpm install --frozen-lockfile`, and `npm pack --dry-run --json`. The Pi 0.80.6 release remains subject to pnpm's minimum-release-age policy; do not create the GitHub Release until the frozen install passes.

The release workflow verifies that the published release tag matches `package.json`, then publishes a normal GitHub Release with npm `latest` through Trusted Publishing.
